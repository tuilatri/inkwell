## 3. GUI — cách dùng

Cửa sổ "comix.to Manga Scraper", 800x700 (min 760x560). Các khu vực:

### 3.1. Nhập series
- **Series URL**: dán URL title, ví dụ `https://comix.to/title/3ek0-shokugeki-no-soma`
- **Get Info**: mở Chrome thật quét toàn bộ pager, lấy title + danh sách chapters. Lần quét đầu hơi lâu, cửa sổ Chrome sẽ **hiện ra** rồi tự đóng.
- **Group** (dropdown): `All groups` (mặc định) hoặc chọn 1 scanlation group cụ thể (chỉ hiện sau khi Get Info). Chọn nhóm → danh sách hiển thị/download chỉ còn chapters của nhóm đó. Hai nhóm cùng dịch một số chapter thì chapter được lưu trong **folder riêng của nhóm**, không đè nhau.
- **Search Query**: đang tắt (under development) — dùng URL trực tiếp.

### 3.2. Nút hành động
| Nút | Việc làm |
|---|---|
| **List Chapters** | In danh sách chapters ra log (số thứ tự + tên + URL) |
| **Download All** | Tải tất cả chapters trong danh sách (đã lọc theo Group nếu có chọn) |
| **Download Range** | Popup hỏi `Enter chapter range (e.g., 1-10):` — **đánh theo VỊ TRÍ** trong danh sách đã lọc, **không phải số chapter**. VD: nhóm Doro toons của series test có 126=vị trí 1, 127=vị trí 2, 128=vị trí 3 → muốn ch.128 thì nhập `3-3` |
| **Select Output Dir** | Chọn thư mục lưu (mặc định = thư mục đang mở GUI) |
| **Stop All Downloads** (đỏ) | Dừng toàn bộ tải đang chạy |
| **Settings** | Xem mục 3.4 |

### 3.3. Checkboxes
| Checkbox | Ghi chú |
|---|---|
| **Convert to PDF** | Convert chapter → PDF sau khi tải (file `chapter.pdf` cạnh folder chapter) |
| **Convert to CBZ** | Convert chapter → CBZ (comic archive) |
| **Keep Images (PDF/CBZ)** | Chỉ bật được khi tick PDF hoặc CBZ; mặc định ảnh gốc **sẽ bị xóa** sau khi convert. Tick ô này để giữ ảnh |
| **Auto-delete Chrome session** | Xóa `comix_downloader\.chrome_profile\` sau khi tải xong (profile chứa cookies/session — không nên commit) |
| **Resume (skip downloaded)** | Bỏ qua chapter đã tải đủ trang trên disk (kiểm tra gap theo số trang reader). Chapter tải dở sẽ được tải lại |

### 3.4. Settings
- **Max Concurrent Chapter Downloads**: 1–10, mặc định **3**
- **Max Concurrent Image Downloads**: 5–30, mặc định **15**
- **Image Format**: `original` (mặc định — WebP gốc của comix) / `png` / `jpeg`
- **JPEG Quality (50–100)**: mặc định **92**, chỉ áp dụng khi format = jpeg
- Chọn png/jpeg mà chưa cài Pillow → log sẽ báo và lưu original

### 3.5. Lỗi import cũ — ĐÃ HẾT nhờ đổi tên thư mục
Trước đây code có dòng `from comix_downloader.comix_scraper import cleanup_chrome_profile` mà thư mục lại tên `comix-downloader` (có dấu gạch ngang) → `ModuleNotFoundError`, GUI treo im lặng khi bấm Download.
**Đã sửa bằng cách đổi tên thư mục thành `comix_downloader`** → câu import chạy đúng khi khởi chạy bằng `python -m comix_downloader gui` từ repo root.
Lưu ý còn lại: nếu chạy trực tiếp `python comix_downloader\gui.py` thay vì `-m`, dòng đó vẫn không resolve được (package không nằm trên search path) — nên luôn dùng đường `-m`.

### 3.6. Luồng chuẩn
1. `python -m comix_downloader gui` (từ repo root)
2. Paste Series URL → **Get Info**
3. (Tuỳ chọn) Chọn **Group**, xem chapters qua **List Chapters** để biết vị trí cần tải
4. **Download All** hoặc **Download Range**
5. Xem progress bar + log; bấm **Stop All Downloads** để huỷ

## 4. CLI — tất cả command

Chạy từ `F:\GitHub_Interesting_Repos\inkwell`:

```
python -m comix_downloader <command> [options]
```

### 4.1 `info` — xem thông tin series

```powershell
python -m comix_downloader info "https://comix.to/title/wv5rr-wireless-onahole" [--group /groups/11494]
```

In title + số chapters; sau đó **hỏi** có liệt kê chapters không (yes/no).
`--group` / `-g`: chỉ giữ chapters của 1 group (href dạng `/groups/NNNN`); bỏ trống = mọi group.

### 4.2 `list` — liệt kê chapters

```powershell
python -m comix_downloader list "<url>" [--group /groups/11494]
```

In dạng `1. Ch.126Doro Toons - 126! [Doro toons] (url)` — cột số đầu chính là **vị trí** dùng cho `--range`.

### 4.3 `download` — tải chapters

```powershell
python -m comix_downloader download "<url>" [OPTIONS]
```

| Option | Mặc định | Ý nghĩa |
|---|---|---|
| `--all`, `-a` | off | Tải tất cả chapters |
| `--range`, `-r` | — | `start-end` theo **VỊ TRÍ** (1-based) trong danh sách đã lọc group. VD: `3-3` |
| `--output`, `-o` | `.` | Thư mục lưu (dấu `.` = thư mục hiện tại) |
| `--max-workers`, `-w` | `3` | Số chapter tải song song |
| `--image-workers`, `-iw` | `15` | Số ảnh tải song song trong 1 chapter |
| `--pdf` | off | Convert → PDF |
| `--cbz` | off | Convert → CBZ |
| `--keep-images` | off | Giữ ảnh gốc sau khi convert (mặc định: **xóa**) |
| `--group`, `-g` | — | Chỉ 1 group, dạng href `/groups/11494` |
| `--format` | `original` | `original` (WebP gốc) / `png` / `jpeg` |
| `--quality` | `92` | JPEG quality 50–100, chỉ dùng với `--format jpeg` |
| `--resume` | off | Bỏ qua chapter đã tải đủ |
| `--verbose`, `-v` | off | Log chi tiết hơn |

Hành vi:
- **Không** truyền `--all`/`--range` → in danh sách scanlation groups rồi thoát (đây là cách dò group id)
- Ước tính ~**14 MB/chapter**; con số thật in ở cuối (tổng bytes đã ghi)
- Exit code: `0` = xong; `1` = có chapter thất bại (in rõ chapter nào); `2` = sai tham số (format/quality)
- Layout output: `<Tên_series>\<Group>\<Chapter>\page_NNN.webp`; PDF/CBZ: `<Chapter>.pdf` / `.cbz` cạnh folder

### 4.4 `gui` — mở GUI

```powershell
python -m comix_downloader gui
```

### 4.5 `search` — CHƯA DÙNG ĐƯỢC

Under development, chỉ là stub (comix không có search). Dùng URL trực tiếp.

## 6. Ví dụ đã TEST THẬT (series "Wireless Onahole")

URL: `https://comix.to/title/wv5rr-wireless-onahole` — title chứa nội dung người lớn; tool chỉ tải file về máy.

```powershell
cd F:\GitHub_Interesting_Repos\inkwell
# 1) Dò groups (như trên) → Doro toons = /groups/11494
# 2) List chapters của Doro toons (3 chapter: 126, 127, 128 → vị trí 1, 2, 3)
python -m comix_downloader list "https://comix.to/title/wv5rr-wireless-onahole" --group /groups/11494
# 3) Chạy thử không kèm option (chỉ dò group) — không tải gì
python -m comix_downloader download "https://comix.to/title/wv5rr-wireless-onahole"
# 4) Tải ch.128 (vị trí 3), lưu vào thư mục hiện tại
python -m comix_downloader download "https://comix.to/title/wv5rr-wireless-onahole" --group /groups/11494 --range 3-3 -o .
#    → 106/106 ảnh, 17.3 MB, exit 0
# 5) Tải + convert PDF, giữ ảnh gốc
python -m comix_downloader download "https://comix.to/title/wv5rr-wireless-onahole" --group /groups/11494 --range 3-3 -o . --pdf --keep-images
#    → PDF 8.87 MB, 106 trang
```

Kết quả CLI thật: OK cho `info`/`list`/`download`. GUI **chưa được mở test** trên máy này.

## 7. Lỗi thường gặp

| Triệu chứng | Nguyên nhân | Cách xử lý |
|---|---|---|
| `Read the title '...' but found no chapters.` | Site chặn/tải chậm — đã gặp 1 lần khi test (4 lần walk: 3 OK, 1 fail) | Thử lại sau vài chục giây; không có gì bị xóa |
| Bấm Download trên GUI xong đứng im / báo `ModuleNotFoundError: No module named 'comix_downloader'` | Chạy GUI trực tiếp thay vì qua `-m` — package không nằm trên search path | Chạy từ repo root: `python -m comix_downloader gui` |
| Chrome treo / nhiều cửa sổ Chrome rác | Tool mở Chrome thật | `Stop-Process -Name chrome -Force` |
| `PIL not available, cannot convert to PDF` | Thiếu Pillow | `pip install Pillow` |
| `undetected-chromedriver` kén phiên bản Chrome | Tool không pin version (tự detect) — đúng thiết kế | Cập nhật Chrome + `pip install -U undetected-chromedriver` |
| Tải xong thiếu ảnh / chapter incomplete | Mạng chập chờn; server chặn giữa chừng | Chạy lại với `--resume` — chỉ tải lại chapter thiếu |
| `.chrome_profile\` phình to (~100MB+) | Profile Chrome thật của tool (cookies, session) | Tick **Auto-delete Chrome session** trong GUI, hoặc xóa tay; **KHÔNG commit thư mục này** (đã có `.gitignore` trong `comix_downloader\`) |
| `python -m comix_downloader` báo `No module named 'comix_downloader'` | Đang đứng sai thư mục (không phải repo root) | `cd F:\GitHub_Interesting_Repos\inkwell` trước khi chạy |

## 8. Dữ liệu & dọn dẹp trước khi commit

- `comix_downloader\.chrome_profile\` — **runtime data, chứa cookies/session** → đã có trong `comix_downloader\.gitignore`; không commit.
- `Wireless_Onahole\` (output test) — tuỳ bạn xoá hoặc giữ; không phải source code.
- `comix_downloader\__pycache__\`, `*.pyc` — đã nằm trong `.gitignore` của repo.
- Output mặc định là `<Series>\<Group>\<Chapter>\` — đừng commit nhầm nếu tải về repo root.
